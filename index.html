Framework · Private

Foundra

My framework for building Expo + Supabase apps. Every app shares the same rules, components, theme and way of tracking work, and a change in one package reaches all of them with a version bump.

  • Rules and a Claude Code plugin so AI agents follow the same architecture, commit, test and verify the same way.
  • A data layer decoupled from the backend: screens never touch Supabase directly.
  • A Hub that records every session, pending task and decision across projects.
